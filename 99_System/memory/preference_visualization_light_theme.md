# Visualization theme preference

**Rule:** Prefer **light theme** over dark theme for all image and visualization deliverables.

## Applies to
- Generated images (diagrams, illustrations, charts, mockups)
- HTML dashboards / interactive reports
- Plots, figures, and data visualizations
- Excalidraw / canvas diagrams
- Slide decks, PDF figures, and any other visual output

## Defaults
- Light backgrounds (white or near-white)
- Dark text and strokes for contrast
- Avoid dark-mode palettes unless the user explicitly requests dark theme for a specific deliverable
