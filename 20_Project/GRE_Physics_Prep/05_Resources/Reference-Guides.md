# GRE Physics Reference Guides & Released Test Forms

## Prep Studio Local Server
To run the local Prep Studio web application:
```bash
cd "/Users/Reid Hu/Physics GRE"
python3 -m http.server 8000
```
Then open **http://localhost:8000** in your browser.

## Official ETS Released Forms
Official released exams are located in the local Prep Studio repository under `20_docs/ETS Released Exams/` and in vault attachments:
- **GR8677** (1986): 100 questions (broken into daily drill questions in Prep Studio)
- **GR9277** (1992): 100 questions (broken into daily drill questions in Prep Studio)
- **GR9677** (1996): 100 questions
- **GR0177** (2001): 100 questions (candidate for Oct 4 Diagnostic)
- **GR0877** (2008): 100 questions (candidate for Oct 4 Diagnostic)
- **GR1777** (2017): 100 questions (legacy paper form for extra problem practice)
- **GR1775 (2024 Practice Book)**: 70 questions, 120 minutes (official computer-based form, reserved for Oct 25 Full Rehearsal)
