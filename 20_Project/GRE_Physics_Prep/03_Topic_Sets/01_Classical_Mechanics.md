# Classical Mechanics Drill Sets (Sets 01–07) · 20% ETS Weight (~14 Qs on 70Q exam)

## Topic Overview
Classical mechanics represents 20% of the exam (~14 questions on the 70-question computer exam). Speed, dimensional analysis, and standard limits are key.

## Problem Set Index

### Set 01: Kinematics & Newton's Laws (25 Qs)
- **Subtopics:** 1D/2D kinematics, projectile motion with/without drag limits, circular motion, inclined planes, friction (static/kinetic), tension systems.
- **Source:** Kahn Ch. 1 Practice Set 1 + ETS Drill Bank (GR8677/GR9277).
- **Target Pace:** ~100 min scheduled (hedge; exam target still ~1.7 min/Q).
- **Log / Status:** `[x] Closed` (2026-09-08 daily sitting)

### Set 02: Work, Energy & Momentum Conservation (25 Qs)
- **Subtopics:** Work-energy theorem, conservative vs non-conservative forces, potential energy curves $V(x)$, 1D/2D elastic and inelastic collisions, center of mass frame.
- **Source:** Kahn Ch. 1 Practice Set 2 + Prep Studio CM Bank.
- **Target Pace:** ~100 min.
- **Log / Status:** `[ ] Open`

### Set 03: Oscillations & Harmonic Motion (25 Qs)
- **Subtopics:** Simple harmonic oscillators (springs, pendulums, torsional), small oscillations around equilibria, damped oscillations ($Q$-factor, overdamped/underdamped), driven oscillations & resonance.
- **Source:** Kahn Ch. 1 Practice Set 3.
- **Target Pace:** ~100 min.
- **Log / Status:** `[ ] Open`

### Set 04: Central Forces & Orbital Mechanics (25 Qs)
- **Subtopics:** Gravitational potential, effective potential $V_{\text{eff}}(r)$, Kepler's three laws, orbital eccentricity, circular orbit speed, escape speed, angular momentum conservation.
- **Source:** Kahn Ch. 1 Practice Set 4 + ETS Form items.
- **Target Pace:** ~100 min.
- **Log / Status:** `[ ] Open`

### Set 05: Rotational Dynamics & Rigid Bodies (25 Qs)
- **Subtopics:** Moments of inertia calculations, parallel and perpendicular axis theorems, torque, angular momentum, rolling without slipping, physical pendulums.
- **Source:** Kahn Ch. 1 Practice Set 5.
- **Target Pace:** ~100 min.
- **Log / Status:** `[ ] Open`

### Set 06: Lagrangian & Hamiltonian Formalism (25 Qs)
- **Subtopics:** Generalized coordinates, setting up $L = T - V$, Euler-Lagrange equations, cyclic coordinates and conserved quantities, constructing Hamiltonian $H$, canonical equations.
- **Source:** Kahn Ch. 1 Practice Set 6.
- **Target Pace:** ~100 min.
- **Log / Status:** `[ ] Open`

### Set 07: Non-Inertial Frames & Fluid Dynamics (25 Qs)
- **Subtopics:** Centrifugal and Coriolis forces, Foucault pendulum, fluid statics (buoyancy, Archimedes), fluid dynamics (continuity equation, Bernoulli's equation).
- **Source:** Kahn Ch. 1 Practice Set 7 + Mixed CM Review.
- **Target Pace:** ~100 min.
- **Log / Status:** `[ ] Open`
