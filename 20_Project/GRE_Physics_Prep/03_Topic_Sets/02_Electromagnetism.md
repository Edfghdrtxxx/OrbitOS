# Electromagnetism Drill Sets (Sets 08–13) · 18% ETS Weight

## Topic Overview
Electromagnetism forms 18% of the test. High-frequency patterns: symmetry in Gauss's/Ampère's laws, boundary conditions, image charges, and LC/RL circuit transients.

Each timed set is a **Prep Studio pack** (`js/data-packs.js`) with honest `n`. Launch: `PGRE.launchPack('08')` → `#/practice/custom`.

## Problem Set Index

### Set 08: Electrostatics & Field Potentials (16 Qs)
- **Studio pack:** `08` · n = 16
- **Subtopics:** Coulomb's law, electric field calculations, electric potential, Gauss's law for spherical/cylindrical/planar symmetries, conductors in electrostatic equilibrium.
- **Source:** Prep Studio pack 08 (preview + Kahn Ch. 2 §2.1 + ETS drills).
