# Laboratory Methods & Specialized Topics Drill Sets (Sets 31–35) · 15% ETS Weight (~10–11 Qs on 70Q exam)

## Topic Overview
Laboratory Methods (6%) and Specialized Topics (9%: Nuclear/Particle, Condensed Matter, Astrophysics) cover the remaining 15% of the exam (~10–11 questions on the 70-question computer exam). High yield items: error propagation, electronics/oscilloscopes, particle classification and conservation laws, crystal lattices, and astrophysics scaling laws.

## Problem Set Index

### Set 31: Lab Equipment, Circuits & Instrumentation (25 Qs)
- **Subtopics:** Oscilloscopes, digital multimeters, operational amplifiers, diodes and rectifiers, bridge circuits, radiation detectors (GM tubes, scintillators, semiconductor detectors).
- **Source:** Kahn Ch. 7 (§7.1 Circuits & Equipment) + Prep Studio Lab Bank.
- **Log / Status:** `[ ] Open`

### Set 32: Error Analysis & Data Reduction (25 Qs)
- **Subtopics:** Systematic vs random errors, standard deviation, error propagation formulas (sum, product, power law), chi-squared $\chi^2$ distribution, linear regression fitting.
- **Source:** Kahn Ch. 7 (§7.2 Error Analysis & Statistics) + Prep Studio Lab Bank.
- **Log / Status:** `[ ] Open`

### Set 33: Particle Physics & Conservation Laws (25 Qs)
- **Subtopics:** Standard Model fundamental fermions and bosons, quark model of hadrons (mesons and baryons), conservation of baryon number, lepton number, strangeness, isospin, fundamental interaction vertices.
- **Source:** Kahn Ch. 8 (§8.2 Particle Physics) + Prep Studio Bank.
- **Log / Status:** `[ ] Open`

### Set 34: Condensed Matter & Solid State Physics (25 Qs)
- **Subtopics:** Crystal structures (SC, BCC, FCC), Bragg reflection $2d\sin\theta = n\lambda$, reciprocal lattice, band theory of solids (conductors, semiconductors, insulators), Fermi energy in metals, superconductivity basics (Meissner effect).
- **Source:** Kahn Ch. 8 (§8.3 Condensed Matter) + Prep Studio Bank.
- **Log / Status:** `[ ] Open`

### Set 35: Astrophysics, Cosmology & Comprehensive Review (25 Qs)
- **Subtopics:** Stellar magnitudes, Hertzsprung-Russell diagram, Stefan-Boltzmann stellar luminosity $L = 4\pi R^2 \sigma T^4$, Hubble's law $v = H_0 d$, cosmic microwave background, comprehensive high-yield formula review.
- **Source:** Kahn Ch. 8 (§8.4 Astrophysics) + Prep Studio Capstone.
- **Log / Status:** `[ ] Open`
