# Optics & Waves Drill Sets (Sets 14–16) · 8% ETS Weight (~6 Qs on 70Q exam)

## Topic Overview
Optics and wave phenomena cover 8% of the test (~6 questions on the 70-question computer exam). Major high-yield topics include interference conditions, diffraction minima/maxima, thin-film phase changes, and Doppler shifts.

## Problem Set Index

### Set 14: Wave Properties, Standing Waves & Sound (25 Qs)
- **Subtopics:** Wave equation, phase vs group velocity, transverse/longitudinal waves, standing waves on strings and pipes, boundary reflection conditions, Doppler effect for sound.
- **Source:** Kahn Ch. 3 Practice Set 1.
- **Log / Status:** `[ ] Open`

### Set 15: Geometric Optics & Polarization (25 Qs)
- **Subtopics:** Snell's law, total internal reflection, critical angle, thin lenses, concave/convex mirrors, lensmaker's formula, optical instruments, Malus's law, Brewster's angle.
- **Source:** Kahn Ch. 3 Practice Set 2.
- **Log / Status:** `[ ] Open`

### Set 16: Interference & Diffraction (25 Qs)
- **Subtopics:** Double-slit interference (Young), single-slit diffraction, diffraction gratings, thin-film interference (dielectric phase shifts), Rayleigh criterion for resolution.
- **Source:** Kahn Ch. 3 Practice Set 3.
