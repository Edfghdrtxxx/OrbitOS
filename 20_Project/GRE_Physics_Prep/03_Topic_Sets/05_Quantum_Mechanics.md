# Quantum Mechanics Drill Sets (Sets 21–25) · 13% ETS Weight (~9 Qs on 70Q exam)

## Topic Overview
13% of the test (~9 questions on the 70-question computer exam). High-frequency patterns: infinite square well energy levels and wavefunctions, harmonic oscillator ladder operators and zero-point energy, commutators and uncertainty, hydrogen atom states, and spin-1/2 algebra.

Each timed set is a **Prep Studio pack** (`js/data-packs.js`) with honest `n`. Launch: `PGRE.launchPack('21')` → `#/practice/custom`.

## Problem Set Index

### Set 21: 1D Wells, Barriers & Bound States (7 Qs)
- **Studio pack:** `21` · n = 7
- **Subtopics:** Infinite square well (symmetric and asymmetric), finite square well, delta-function potentials, barrier tunneling and transmission coefficients, parity and node theorem.
- **Source:** Prep Studio pack 21 (preview + Kahn Ch. 5 §5.3 + ETS drills). Honest short `n`.
- **Log / Status:** `[ ] Open`

### Set 22: Harmonic Oscillator & Operator Algebra (7 Qs)
- **Studio pack:** `22` · n = 7
- **Subtopics:** Harmonic oscillator energy spectrum $E_n = (n + \frac{1}{2})\hbar\omega$, raising and lowering operators $a, a^\dagger$, commutators $[x, p] = i\hbar$, uncertainty products, expectation values $\langle x^2 \rangle, \langle p^2 \rangle$.
- **Source:** Prep Studio pack 22 (preview + Kahn Ch. 5 §5.1–5.2 + ETS drills).
- **Log / Status:** `[ ] Open`

### Set 23: Formalism, Superposition & Measurement (18 Qs)
- **Studio pack:** `23` · n = 18
- **Subtopics:** Postulates of quantum mechanics, state vectors, Dirac bra-ket notation, Hermitian operators and real eigenvalues, probability of measurement outcomes, time evolution operator.
- **Source:** Prep Studio pack 23 (preview + Kahn Ch. 5 §5.1 + ETS drills).
- **Log / Status:** `[ ] Open`

### Set 24: Hydrogen Atom & 3D Potentials (5 Qs)
- **Studio pack:** `24` · n = 5
- **Subtopics:** 3D spherically symmetric potentials, orbital angular momentum $L^2, L_z$, spherical harmonics $Y_{lm}$, hydrogen atom energy levels $E_n \propto -1/n^2$, degeneracy, radial wavefunctions.
- **Source:** Prep Studio pack 24 (Kahn Ch. 5 §5.4 + ETS drills). Honest short `n` — not padded off-theme.
- **Log / Status:** `[ ] Open`

### Set 25: Spin, Perturbation Theory & Identical Particles (10 Qs)
- **Studio pack:** `25` · n = 10
- **Subtopics:** Spin-1/2 algebra, Pauli spin matrices, addition of angular momenta, time-independent perturbation theory (first-order energy and state corrections), fermions and bosons, Pauli exclusion principle.
- **Source:** Prep Studio pack 25 (Kahn Ch. 5 §5.5–5.6 + ETS drills).
