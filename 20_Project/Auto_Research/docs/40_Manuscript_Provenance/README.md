# Manuscript and provenance audits

Reports tracing manuscript claims to artifacts, methods, figures, related work, and the campaign closing document.

## Contents

- [[fm-ar-claims-ledger|Claim-by-claim evidence ledger]] — Traces every scientific claim in the paper draft directly to underlying run artifacts and data tables.
- [[fm-ar-bib-fixsheet|Bib fix sheet for references.bib]] — Paste-ready corrections for fabricated, wrong-DOI, miscited, and uncited entries, every identifier verified live against Crossref/arXiv; companion `fixes.bib` named but not copied.
- [[fm-ar-closing-check|Closing-document statement check]] — Evaluates narrative statements in closing documents against empirical results.
- [[fm-ar-figure-provenance|Figure provenance audit]] — Maps draft figures and plots back to generation scripts and input run data.
- [[fm-ar-methods-audit|Methods versus code]] — Audits manuscript text descriptions against actual PyTorch model and data loading implementations.
- [[fm-ar-related-work|Related-work and novelty audit]] — Verifies literature citations, DOI correctness, and prior-art positioning.
