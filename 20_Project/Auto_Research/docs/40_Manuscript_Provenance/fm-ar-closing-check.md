## Claims the closing doc should add

Ordered by reader impact. All are scout findings the doc does not currently contain.

1. **EXP2's "³He/⁴He" runs are α-vs-rest with carbon-contaminated negatives** (label-blast §1.3). The EXP2 3He4He configs globbed 7 files — 5 species + 13C/14C written into `Garfield_HC/` on 2026-03-18 — so those numbers are α vs {p,d,t,³He,¹³C,¹⁴C} on a 35k val, not comparable to EXP1's 25k-val task even before the naming issue. Manuscript §5.5 (L381) is directly affected.
2. **V6 Table 4 is unsettled** (label-blast §1.4). Whether the published V6 2×2 was α-vs-Nonα or the *same triton bug* hinges on the Windows files' label values at Feb-2026 run time — decidable in ~1 min of h5py on the Windows box (check `t` file: label 4 → OLD-mapped → V6 buggy; label 2 → v6). Comparative XA-vs-RN deltas survive either way; the task identity and α-recall column are what's at risk.
3. **Physics features are unnormalized by design — and the manuscript says the opposite** (feature-norm §1/§5, methods-audit M1). `Izz`≈170 contributes a ~386-norm DC to the query and fixes 108/128 hidden ReLU signs (measured on the EXP8 XA checkpoint) — a concrete mechanism for "crowding" that is *scale*, not information. `main.tex:170,207` claims standardization that never ran (also false for the legacy published runs). This reframes the whole mechanism section: `permuted_q`/`zero_q`/`zero_cls` results are all consistent with a magnitude artifact.
4. **Token 50 is not the beam hole; the sink is a learned register** (attn-sink §1). Token 50 = edge-adjacent near-empty block (y∈[64,72), z∈[16,24)); beam hole is tokens 23/29/35/41/47. The honest framing: "image-driven attention pooling + parallel physics concat" — the cross-modal part is vestigial in the attention branch. The doc's §3 should adopt this.
5. **The HC−Raw gap is image-side denoising, proven by the physics-free arm** (hc-vs-raw §1-4). RN gains +6.5pp on HC with zero physics exposure → the entire representation gap lives in the image (DBSCAN removes ~94% of pads; Raw Ch0 track below σ≈0.028 noise floor). Physics features are computed from Ch0 → redundant on HC, the head's only global statistic on Raw. This is the campaign's cleanest mechanism result and is absent from the doc.
6. **Manuscript §5.5's "³He/⁴He" controlled experiments are mislabeled α-vs-Nonα on Garfield_HC** (methods-audit M2, hehe-control Part 1). The flagship NimpSim margin was never decomposed; no matched XA-vs-RN exists on real ³He/⁴He at any size. EXP3's triton result (−1.3/−2.1pp on Raw) further suggests the V6 "+1.6pp Raw" advantage was a data-scale confound, not mechanism.
7. **Kuchera baseline has the same label bug** (code-audit §1). `src/baselines/kuchera.py:65-73` hard-codes `{4:0}` + names class 0 "Alpha (4He)" → every `alpha_recall` it reports is triton recall unless `file_class_list` is supplied. Any Kuchera arm pinned to a triton-task EXP3 split inherits triton semantics (label-blast Q6).
8. **Two analysis-code bugs gate pending results** (code-audit §2/§3/§4): (a) `exp3_threshold_sweep.py` can emit a false "calibration" verdict — it checks acc-closure and bal-acc-closure at *different* thresholds instead of one joint threshold; (b) `paired_stats.align_pair` silently drops label mismatches and accepts duplicate event IDs. Both must be fixed/known before the predump-chain outputs are quoted.
9. **Battery statistics caveats** (referee A4): n=2000 → Δ≤0.0005 bounds effects at <~0.2% of predictions, not zero; subset identity unrecorded in JSONs (add `event_indices` + script-version field); battery runs on the val split used for checkpoint selection (mild optimism on `original`, deltas unaffected).
10. **Tighter guaranteed McNemar bounds exist** (gpu-ladder §2.2): p≤1.5e-5 / p≤4.5e-12 for the two Raw seeds — supersedes the nΔ² floor quoted in §13.
11. **Balanced-accuracy recomputation** (referee §B.4): the Raw deficit survives balancing (−2.7/−4.6pp) — the deficit is not purely a threshold artifact; the threshold-sweep check is still queued.
12. **Locked preregistered predictions for the pending conditions** (mechanism §3): a dated rival-model prediction table for `permuted_cls`/`mean_cls`/`scaled_cls`/`clipped_cls`/`centered_q`/channel ablations/`swap_physics`/map-level `permuted_q`/threshold sweep — cite it when D5/D6 land so the readouts are scored against predictions, not rationalized.
13. **GPU budget ladder + billed-wall caveat** (gpu-ladder Part 1): consolidated de-duplicated run list (R1–R10); observed XA-Raw run-dir wall ×2.8 vs logged train → budget Raw cells ~7h billed, not ×1.3. Supersedes seed-evidence's stale cost figures.
14. **Z01 transfer facts** (transfer §3): moments-LR arm reproduced locally at 0.7009 bal-acc (exact cross-check vs `model.npz`); flattened-pixel LR = 0.9215 — the honest traditional-baseline anchor on the public set; ResNet18 hit val 1.0000 (ceiling — direction B can only ever tie).
15. **Per-species triton-task confusion** (label-blast §2.4): dominant confusion is d→t (3.6%), 4He→t only 0.7% — the triton task is a real stopping-power discrimination problem, which is why the XA<RN Raw deficit on it is meaningful as a mechanism result.
16. **Augmentation is a silent no-op** (hehe-control §1c, gpu-ladder §1.4): `dataset.py:587-588` — any future run config assuming augmentation (e.g. NimpSim Option B) silently runs without it.
