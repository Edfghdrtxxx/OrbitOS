# Learnings

- 2026-09-22: On Herdr, an omp worker's reviewers appear only as a Subagents tree on the parent screen. `herdr agent list` does not list them. A star on a row means that reviewer is still running, and the parent stays working until those reviewers finish. The line under the tree that starts with `esc Inspect` sits in the input area. The screen check then treats the prompt as holding unsent text, so a saved instruction is not typed and quit is refused. Escape and clear-line did not change that verdict for the strikethrough, power-symbol, similar-problem, and studio workers. Do not treat that screen as an empty prompt.
- 2026-09-23: `fm-procevent-when.sh` condition/action argv paths must not contain spaces: the runner's perl timeout does `exec @ARGV`, and a single-element list with a space goes through `/bin/sh`, which splits the path (e.g. `Reid Hu`) and fails with ENOENT → exit 255 → `condition-error`. Keep watch scripts under a space-free path (e.g. `/tmp/fm-when/`). Separately, condition scripts run in a stripped environment — no `HOME`, minimal `PATH` — so pin `HERDR_ENV=1` (required gate; `HERDR_SOCKET_PATH` alone is ignored), `HERDR_SOCKET_PATH=/Users/leyi/.config/herdr/herdr.sock`, and absolute binary paths (`/Users/leyi/.local/bin/herdr`, `/usr/bin/jq`). Test with `env -i` before arming.
- 2026-09-24: The Bash tool runs zsh, which does not word-split an unquoted `$p`. A loop like `for p in "id url" ...; do set -- $p; fm-pr-merge.sh $1 $2` therefore passes one argument and fails with "invalid PR merge request". Teardown still succeeds on a pushed-but-unmerged direct-PR branch, and it deletes the task metadata that `fm-pr-merge.sh` needs, so the guarded merge then refuses with "task metadata is unavailable". Run each merge as its own explicit command, confirm "is merged", and only then tear down. (MATE #34 and OrbitOS #7 were recovered this way; the captain approved a direct `gh pr merge --match-head-commit`.)
- 2026-09-25: `fm-control.sh <id> exit|relaunch` failed on an idle Claude worker on Herdr with "the exit command could not be sent". The Claude path types `/exit` and then checks that the composer shows it. `fm_backend_herdr_composer_content` read the composer as empty while Claude's slash popup was open, even though the pane showed `❯ /exit`. It then cleared the text and reported send-failed. This was seen with the 4-line statusline under the composer. Separately, `fm-control interrupt` on an idle Claude opened the Rewind menu, and a second interrupt cancelled it. Workaround: type `/exit` with the herdr adapter's `fm_backend_herdr_send_literal`, submit with `fm-send.sh <id> --key Enter`, then relaunch. The relaunch sees the agent gone and proceeds (fm-jev-route-scout, Opus to Grok 4.6).
