# Speaking Collocation Review — Guide & Notes

> [!info] Scheduling is owned by the plugin
> The manual review-state table was retired. The **Obsidian Spaced Repetition** plugin schedules
> every card in [[Speaking_Collocation_Bank]] using its SM-2 algorithm and stores each card's
> review data inline as an `<!--SR:...-->` comment next to the card. There is nothing to update
> by hand.

## One-time setup

1. In Obsidian: **Settings → Community plugins → Browse**, search **"Spaced Repetition"**
   (by Stephen Mwangi / st3v3nmw), install, and enable it.
2. Open the plugin settings and confirm **Flashcard tags** includes `#flashcards` (the default).
   The bank uses the nested deck `#flashcards/toefl/speaking`, which sits under it automatically.
3. No separator changes needed — the bank uses the plugin defaults: `??` for multi-line
   bidirectional cards.

> Source (primary): [plugin docs](https://stephenmwangi.com/obsidian-spaced-repetition/),
> [Q&A card formats](https://stephenmwangi.com/obsidian-spaced-repetition/flashcards/q-and-a-cards/).

## Daily review (~5/day)

- Run the command **"Spaced Repetition: Review flashcards"** (or click the plugin's sidebar icon),
  then choose the **toefl/speaking** deck.
- For each card, say the phrase **aloud in a full sentence** before flipping, then rate it
  (Easy / Good / Hard) — the plugin sets the next due date.
- Each phrase is **bidirectional**: you'll see cue → phrase and phrase → cue as sibling cards.
