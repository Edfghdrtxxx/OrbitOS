# Evolution Log

## 2026-09-03
### Lessons
- **Tab indentation for nested subtasks:** In Obsidian, nested subtasks must be indented with a literal Tab (`\t`), never 2 spaces, so that Markdown task list hierarchy renders correctly in preview and live preview.
- **In-place replacement:** When decomposing a task that already exists in the daily note, replace it directly in its current bucket while preserving context and wikilinks.
