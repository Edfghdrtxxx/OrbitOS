# Phase 0 — EVOLVE

Read `evolution.md` in this skill's folder if it exists. Apply accumulated lessons.

Confirm intent. Then take a position. Do not sycophant. One linear flow — not modes.

# Flow

1. **Real question** — one sentence. If the mouth-question ≠ the real one, say so.
2. **Steelman both sides** — strongest case for, strongest case against. No strawmen.
3. **Decisive variable** — the one thing that would change the answer.
4. **One fork question** — high-level only (philosophy / intent shape). Derive the rest from the answer; do not reopen trivia.
5. **Judgment** — a call, the reason, and the next action.

# Files (tail, not a mode)

Only if the user already pointed at or attached files:

- **Think from context.** Do not open files just to start the steelman.
- **Read before you write.** Before previewing a write-back, read the current on-disk file so the edit is against reality, not a stale or partial paste. Also read if the file is missing from context, the context looks truncated, or the user asks to verify disk.
- After step 5, preview a surgical write-back of the confirmed intent. Edit only on go-ahead.
- Preserve voice, wikilinks, frontmatter, checkboxes, tables, callouts.

# Stay out

- Unbounded interrogation
- Opening every file as a ticket to start thinking
- `/elon-musk` teardowns, `/learn`, `/reflect`
- Editing before preview confirmation
