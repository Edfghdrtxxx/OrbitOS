# Evolution Log

## 2026-09-03
### Lessons
- **Multi-section task breakdown:** When a captured idea explicitly spans multiple distinct sections or sub-steps (e.g., "practice 4 sections respectively"), do not leave it as a monolithic flat checkbox. Decompose it into a parent checkbox with nested subtasks and per-section time estimates.
- **Tab indentation for nested subtasks:** In Obsidian daily notes, always indent nested sub-checkboxes with a literal Tab (`\t`), never 2 spaces, to ensure proper Markdown list hierarchy rendering.
- **Auto-feedback loop for deliberate practice:** Active generative practice, test, or problem-solving tasks require an immediate debrief phase. Never capture them as solitary unchecked items; decompose them into a parent session with nested execution and debrief subtasks (dual subtasks for standalone drills, paired subtasks for multi-section drills).
