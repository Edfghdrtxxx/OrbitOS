### Tutor

Yes — (1)+(2)+(4) is still a complete winter-hours mail. So (3) stays a sticker.

Those four words are **not** four independent hunt chips. They are one **confirm-family bundle**:

**[whose] + [the booked thing] + [lock-in verb]**

- *Your Saturday booking of Lane 3 **is confirmed.***
- *Your Tuesday 2:00 p.m. slot **is reserved.***

Same family, not a second list: *booking, reservation, appointment, is yours, held for you, signed up.* Still only fire when they lock **a time/thing to a person**.

Isolated chips lie. Item 6’s *your ID* has *your* and is still a sticker: *your* + object, **no lock-in verb**. That is why a word list will re-create the safety-module miss.

**Correspondence is job-to-job, not noun-to-noun.**

```
PACKAGE in the body              GREEN option starts with
─────────────────────────────────────────────────────────
your/slot is reserved|confirmed  To confirm a booking /
                                 reservation / slot
                                 (+ its conditions)

will now / will not / starting   To announce a change /
not 10 p.m. / no longer          new hours / new rooms

reply / submit / if you want     To request that you
by Friday                        do X

how to / follow these steps      To explain how to
```

The green option may **also** name stickers (*and its conditions*, *and the ID rule that goes with it*). That is allowed. A trap option names **only** a sticker noun (*safety-orientation*, *handout*, *lifeguard card*) and slaps a **wrong job** on it (*announce*, *explain*).

Same words as the passage + wrong job → reject. Different words + same job → take it. That is the same judgment gate as the paraphrase thread, applied to purpose.
